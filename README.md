# SRM Semester Calendar

Google Calendar-style static website for the SRMIST Faculty of Engineering and Technology, Kattankulathur.

## Included

- Full academic calendar: 21 July 2026 to 7 December 2026
- SRM Day Order mapping (Day 1–Day 5)
- Holidays from the supplied portal data
- Month / Week / Day views
- Full subject names
- Classroom and lab labels
- Locations
- FREE periods in Day view
- Day 2 Programming for Problem Solving LAB corrected to Slots 3 and 4

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all five files.
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save.

Your calendar will then be available through the GitHub Pages URL.

## Files

- `index.html` — page structure
- `style.css` — design
- `app.js` — calendar functionality
- `data.js` — timetable and academic calendar data
- `README.md` — instructions
